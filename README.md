# ROYAL+ Launcher

An independent Android TV / TV Box home launcher with a royal black-and-gold interface.

## Project identity
- Repository: `Ramistar900/royalplus-launcher`
- Android application ID: `com.royalplus.launcher`
- Default branch: `main`

## Current foundation
- Android TV Home intent and Leanback launcher entry points
- Remote-friendly, focusable app grid
- Installed launcher app discovery and app launching
- GitHub Actions debug APK build

Weather, configurable wallpapers, shortcuts, and persistent preferences are planned for later, separate steps. This project is independent from Almalaki and ROYAL TV.
